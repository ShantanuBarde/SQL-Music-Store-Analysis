
# 🎵 Music Store Data Analysis Using SQL

## 📌 About the Project
This project analyzes a digital music store database using SQL to extract meaningful business insights related to customers, invoices, artists, albums, tracks, and music genres.

The project includes Basic, Moderate, and Advanced SQL questions to practice SQL queries and solve real-world business problems.

## 🛠️ Tools & Technologies
- SQL
- PostgreSQL
- pgAdmin

## 📂 Project Files
- **SQL_Queries.sql** – Contains all SQL queries and solutions.
- **Questions.txt** – Contains the SQL questions categorized by difficulty.
- **Database_Relationship.png** – Shows the database schema and relationships between tables.

## 📊 Questions Solved

### 🟢 Basic Level
1. Identify the senior-most employee based on job level.
2. Find the country with the highest number of invoices.
3. Retrieve the top three invoice totals.
4. Identify the city generating the highest revenue.
5. Find the customer who has spent the most money.

### 🟡 Moderate Level
1. Identify customers who listen to Rock music.
2. Find the top 10 artists with the most Rock tracks.
3. Retrieve tracks longer than the average song duration.

### 🔴 Advanced Level
1. Analyze customer spending on the best-selling artist.
2. Find the most popular music genre in each country.
3. Identify the highest-spending customer in each country.

## 🗃️ Database Schema

The database includes the following tables:

## 📚 SQL Concepts Covered

## 🚀 How to Run
1. Clone or download this repository.
2. Set up the music store database in PostgreSQL.
3. Open `SQL_Queries.sql` in pgAdmin or another SQL editor.
4. Refer to `Questions.txt` for the problem statements.
5. Execute the queries and analyze the results.
